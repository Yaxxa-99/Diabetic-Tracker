# Diabetic-Tracker
Diabetic Tracker is a PHP + MySQL based web application developed to manage and monitor diabetic patients in a medical center diabetic ward efficiently. This system helps healthcare staff maintain accurate patient records, track blood sugar levels, manage appointments, monitor treatment progress, and improve overall patient care.

The system is designed to reduce manual paperwork, minimize errors, and provide quick access to patient information for doctors, nurses, and administrators. It includes features such as patient registration, medical history management, blood glucose tracking, medication monitoring, report generation, and user-friendly dashboard access.

This project was built with the goal of improving workflow efficiency in diabetic ward operations while ensuring better data organization and faster decision-making for healthcare professionals.
